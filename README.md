## 1. 痛点与解决方案

| 传统 CAD 审图困扰 | CAD Auto CloudNote 解决方案 |
|:---|:---|
| **图文零散游离**：原生 `REVCLOUD` 云线、文字与引线各自独立，移动或改图时图文极易脱节错位 | **图文成套一体化绑定**：在单一事务中成套绑定云线、引线与 MText，注入唯一 NoteId 扩展数据，移动夹点与删除完全联动 |
| **删除留有残片**：工程师用 Erase 删除文字或云线，往往残留折角引线或孤儿箭头 | **级联安全删除**：监听反应器，删除引线、三角形箭头、文字或云线任一图元，整套批注连同看板项联动彻底清理 |
| **严重程度靠肉眼查**：所有云线全是一个颜色，无法一眼看出哪些是“紧急强条”哪些是“一般优化” | **严重等级颜色联动**：一般(绿)、重要(品红)、紧急(红)自动映射，新建批注自动按等级赋色，出图直观分级 |
| **审图打字重复繁琐**：诸如“请核对门窗洞口尺寸”、“配筋不符”等重复文字需反复手工输入 | **常用审查意见词典**：内置高频工程意见快捷词条库，支持一键点选填入与自定义增删扩充 |
| **DWG 数据膨胀残留**：图纸经过长期修改与拷贝，大量无效 XRecord 滞留在扩展字典形成幽灵数据 | **一键图纸健康体检**：深度扫描当前 DWG 数据库，自动识别与清理无图元关联的孤儿 XRecord，释放文件空间 |
| **清单需手工二次录入**：向业主汇报或归档时，需在 Excel 中重复手打批注内容，耗时且易漏项 | **零依赖一键导出**：一键生成带样式的原生 Excel 表格、标准 CSV 及 DWG 内置 CAD Table 汇总表 |

## 2. 核心系统特性

### 2.1 三大云线绘制模式与曲线转换

系统提供三种基于真实圆弧拟合的交互绘制引擎，并支持已有几何对象一键转换：

```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐  
│   矩形云线 Jig   │       │  多边形云线 Jig  │       │   徒手画云线 Jig │  
│ 两点拉框快速生成 │       │ 任意顶点多边形闭合│       │  光标轨迹实时追踪 │  
└─────────────────┘       └─────────────────┘       └─────────────────┘  
                                   │  
                    ┌──────────────┴──────────────┐  
                    │ Shoelace 多边形内外凸自适应  │  
                    │ 自动计算顶点走向，圆弧始终外凸│  
                    └─────────────────────────────┘
```

1. **矩形云线 (`RectCloudJig`)**：通过两点框选，根据出图比例自适应计算 X/Y 方向整除步长，圆弧均匀向外隆起，拐角严丝合缝；
2. **多边形云线 (`PolygonCloudJig`)**：支持图面拾取任意数量控制顶点，内置 **Shoelace 算法（鞋带定理）** 计算多边形有向代数面积，自动识别用户顺时针或逆时针点击顺序，精准确定外法线方向，确保凹多边形与凸多边形的所有圆弧均向外饱满隆起，杜绝倒向内翻与几何破面；
3. **徒手画云线 (`FreehandCloudJig`)**：适合异形与曲面区域的随心草绘；
4. **对象转云线 (`CNCONVERT / CNCV`)**：支持选取图面已有 Polyline、Circle、Ellipse 或 Spline，原地重构为符合工程规范的标准圆弧云线批注；
5. **追加云线 (`CNADDCLOUD / CNAC`)**：允许向已有批注追加副云线框与分枝引线，实现“一处文字、标注多处隐患”。

### 2.2 图文成套一体化绑定、级联删除与夹点拖拽联动

批注由【云线多段线】、【引线】、【箭头多段线】与【MText 多行文字】共同组成成套实体系统：

```text
┌─────────────────────────┐  
│     成套批注复合图元    │  
└────────────┬────────────┘  
┌────────────┼────────────┐  
▼            ▼            ▼  
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐  
│   云线 Polyline │  │ 折角引线 / 箭头 │  │  MText 多行文字 │  
└─────────────────┘  └─────────────────┘  └─────────────────┘  
│                    │                    │  
└────────────────────┼────────────────────┘  
                     ▼  
         XData 注入唯一 GUID NoteId  
                     │  
      ┌──────────────┴──────────────┐  
      ▼                             ▼  
┌─────────────────────────┐   ┌─────────────────────────┐  
│ 级联删除 (Cascade Erase)│   │ 夹点拖拽 (Grip Edit)    │  
│ 删除任一图元，触发整套  │   │ Application.Idle 监听   │  
│ 联动清理与看板同步移除  │   │ 消除坐标滞后，位移同步  │  
└─────────────────────────┘   └─────────────────────────┘
```

- **级联安全删除**：通过 `ReactorManager` 监听 `ObjectErased`。无论在图面按 Delete 删除了标注文字、云线框还是引线三角形，系统均自动级联清理整条批注绑定的所有图元及 NOD 扩展字典，看板列表即时同步刷新，图面干净无残留；
- **夹点拖拽实时同步**：挂载 `Application.Idle` 机制。用户通过鼠标夹点移动文字或引线端头时，图元在鼠标释放瞬间精准同步位置，杜绝出现视觉残影或坐标漂移。

### 2.4 极速免弹窗批注与 8 大黄金短语库

为了满足工程图纸高频标注、海量消项对极致效率的严苛要求，CAD Auto CloudNote 打造了全流程**极速免弹窗批注体系**：

```text
极速免弹窗触发 (CNQ 或底栏勾选)  
│  
┌──────────────┴──────────────┐  
▼                             ▼  
[1. 框选云线范围]             [2. 动态引线与文字 Jig]  
│                             │  
│              ┌──────────────┴──────────────┐  
│              ▼                             ▼  
│        按 S 单键切词                按 T 临时键入  
│      (1~8 键秒选黄金短语)        (命令行输入定制意见)  
│              │                             │  
└──────────────┬─────────────────────────────┘  
▼  
[3. 秒级极速落图完成]
```

1. **秒级免弹窗落图**：使用快捷命令 `CNQ`（或在设置底栏勾选“极速免弹窗批注”），框选云线并点选引线后，系统直接以预设短语完成批注并落图；
2. **命令行动态切词 (`S / T` 键)**：在引线拖拽阶段，用户可在命令行敲击 **`S`** 呼出 8 大黄金精炼短语菜单（与设置 UI 完全一致：1-待修改、2-请核实、3-请补充、4-请复核、5-待确认、6-核对有误、7-信息不全、8-做法不明），按数字键 1~8 秒切；或敲击 **`T`** 临时输入定制内容；
3. **高频常用短语库**：内置收录建筑、结构、给排水、电气、暖通空调、通用等各专业常用短语库；
4. **状态栏双向联动**：全局设置视窗底部常驻极速模式开关与默认短语下拉选择框，勾选即激活，并提供帮助与系统默认值恢复按钮。

### 2.6 5级生命周期状态机与动态变色

```text
[草稿 (Draft)] ──> [待办 (Pending)] ──> [已改 (Resolved)] ──> [已闭环 (Closed)]  
                         │                    │  
                         └───<─ [驳回 (Rejected)] ─<──┘
```

- **待办 (Pending)**：ACI 1 号色（鲜红），警示未整改缺陷；
- **已改 (Resolved)**：ACI 3 号色（翠绿），提示修改完毕待复核；
- **已闭环 (Closed)**：ACI 8 号色（中灰），归档完成不干扰正常出图；
- **驳回 (Rejected)**：ACI 6 号色（品红），提示存疑待进一步沟通。

### 2.10 链式SHA256防篡改审计追溯

- 每次创建、修改、状态流转与回复均生成链式哈希：  
  $\text{CurrentHash} = \text{SHA256}(\text{PreviousHash} + \text{Action} + \text{Diff} + \text{Time} + \text{Operator})$
- 输入 `NOTEAUDIT` 即可回溯历史证据链，验证修改记录真实性。

## 3. 极速上手流程 (5 步操作流程)

```text
[步骤1: 展开看板] ──> [步骤2: 新建云线] ──> [步骤3: 填入意见] ──> [步骤4: 整改流转] ──> [步骤5: 导出报表]  
    CNP (看板)       CNOTE / CN / CNQ      常用短语/规范库快速填充     CNR (回复)            CNP面板 / NOTEOUT
```

1. **展开看板**：在命令行输入 `CNP`，协同管理看板自动停靠展开；
2. **新建云线**：输入 `CNOTE`（或 `CN`）框选区域；日常高频推荐使用 `CNQ` 免弹窗极速批注，拉框后直接落图，配合单键 `S`（1~8 黄金短语）与 `T` 键即时切换常用意见；
3. **填入意见**：在弹出的对话框中选择常用意见短语或手动输入内容；
4. **整改流转**：设计修改后点选批注，输入 `CNR`（或在看板中点击回复）将状态切为“已改”，云线秒级变绿；
5. **导出报表**：在看板内一键导出全项目 Excel 审查清单，或输入 `NOTESUMMARY` 绘制图面汇总表。

## 8. 常见问题解答 (FAQ)

**Q1：安装包安装在哪个目录？**  
A：统一安装在 `%AppData%\Roaming\InkVerse\CadAutoCloudNote`，为当前 Windows 登录用户独立运行目录，绿色不污染系统盘系统文件夹。

**Q2：打开导出的 Excel 文件乱码怎么办？**  
A：本插件导出的 CSV 自带 UTF-8 BOM，导出的 `.xls` 为标准 XML Spreadsheet 2003，无论在 WPS、微软 Office 还是 macOS Excel 均可正常解析中文与单元格换行。

**Q3：天正建筑图纸比例如何适配？**  
A：插件内置比例探测引擎，输入 `NOTEADAPT` 即可自动计算当前图纸的有效比例因子，确保云线与文字大小与工程图框比例协调。

**Q4：删除标注文字后引线还会留在图面上吗？**  
A：不会。系统内置级联删除反应器闭环机制，删除引线、三角形箭头、文字或云线任一部分，整条批注均自动安全清除。

**Q5：参数设置改乱了如何恢复？**  
A：输入 `CNS` 打开参数设置面板，在第 5 板块【快捷与系统】中点击“恢复系统默认”按钮（或直接删除 `%AppData%\Roaming\InkVerse\CadAutoCloudNote\settings.json`），插件将自动重新载入出厂经过实测验证的系统基准配置。
