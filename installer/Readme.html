CAD 云线批注 (CAD Auto CloudNote) 使用指南

架构内核: C# 共享项目 (Shared Project) 跨代支持: AutoCAD 2007 ~ 2027 (R17 ~ R27 全覆盖) 开源协议: GNU AGPL v3.0

项目说明：本项目非商业官方软件，是作者在工程一线设计之余，利用个人业余时间出于技术爱好和实际绘图需求编写的开源辅助小工具，免费分享给有需要的施工、设计与校审同行。

1. 系统概览与核心架构

为什么选择 CAD Auto CloudNote？

传统 CAD 审图通常面临“批注零碎、图文脱节、改图难溯、删除留残、严重程度难辨”等顽疾。CAD Auto CloudNote 通过实体级 XData 绑定、DWG 扩展字典（NOD）4+2分片存储、多文档隔离反应器、五大设置板块及严重等级颜色联动，建立严密的数字化审图作业闭环：

  • 复合图元与级联删除：云线、引线、MText 封装在单一事务中，删除任一部分自动级联清除全套图元与字典，杜绝孤儿图元残留。
  • 严重等级颜色联动：一般(绿)、重要(品红)、紧急(红)自动映射，新建批注自动按等级赋色，出图视觉警示直观分明。
  • 常用审查意见快捷词典：内置高频工程审查短语，支持即时新增、删除与一键恢复预设，大幅减少重复敲字。
  • 一键图纸健康体检：深度遍历图纸数据库，自动清理孤儿 XRecord 与无效扩展字典，轻量化压缩图纸存储。
  • 分卷隔离保障稳定：50 条批注自动分卷隔离机制，单张图纸承载大量批注保障图纸操作稳定流畅。

2. 核心功能套件

2.1 三大云线绘制与曲线转换 (`CNOTE` / `CN` / `CNCV` / `CNAC`)

插件提供多种贴合工程实际的云线绘制与重构方式，自动基于图纸标注比例（`DIMSCALE`）与天正出图比例换算适宜弧长：

矩形云线 (`RectCloudJig`)

交互指定对角两个角点，系统根据步长在长宽方向整除分布圆弧，拐角对称平顺闭合，无破碎残弧。

多边形云线 (`PolygonCloudJig`)

支持连续拾取任意顶点多边形。内置 Shoelace 鞋带算法 实时计算有向代数面积，自动判别顺时针/逆时针走向与外法线方向，确保凹凸多边形圆弧始终饱满外凸，杜绝倒翻破面。

书法笔锋变截面

支持起笔细、落笔粗变截面毛笔笔锋渲染，赋予云线工业工程手绘质感。

对象转云线 (`CNCV` / `CNCONVERT`)

选取已有 Polyline、Circle、Ellipse 等曲线，原地转换为标准工程云线批注。

追加云线 (`CNAC` / `CNADDCLOUD`)

为已有批注追加副云线框与分枝引线，实现“一处审查文字、覆盖多处图面隐患”。

2.2 图文成套一体化绑定、级联安全删除与夹点拖拽实时同步

批注由云线多段线、折角引线、箭头三角形多段线与多行文字组合构成，系统在底层构建了完备的响应式联动保护：

级联安全删除 (Cascade Erase)

无论工程师使用 AutoCAD 原生 Erase 删除了文字、引线还是不小心删除了箭头三角形，反应器均能自动捕获并级联清理整条批注绑定的所有关联图元，同步从 NOD 字典与右侧管理看板中安全移除，绝不在图面上留下无主死引线。

夹点拖拽实时同步 (Application.Idle)

针对 AutoCAD 夹点编辑（Grip Edit）在拖拽文字或引线端头时不触发 CommandEnded 的行业痛点，系统挂载 Application.Idle 线程空闲探测，拖拽松开瞬间精准对齐，消除视觉残影与坐标漂移。

2.3 全局设置五大板块与实用联动机制 (`CNS` / `CNOTESET`)

全局参数设置视窗采用全新的五大板块架构设计，WPF 与 WinForms 均支持深色工程护眼与浅色明亮双色自适应（自动跟随宿主 COLORTHEME 变量），保持 100% 结构与体验对等：

全局设置五大板块架构

【实用联动】严重等级与颜色联动

开启联动后，新建批注时根据所选优先级（一般/重要/紧急）自动赋予对应的云线颜色（默认：一般=绿 3、重要=洋红 6、紧急=红 1），省去手动换层换色的繁琐，图面警示层级清晰。

【图纸维护】图纸批注健康体检与清理

一键深度扫描当前图纸的 NOD 命名对象字典，彻底清理无实体关联的孤儿 XRecord、幽灵扩展字典与失效句柄引用，减小 DWG 图纸体积并净化图纸环境。

【便捷交互】标题栏与底栏双“帮助”直达

设置视窗顶部标题栏右上角（关闭按钮左侧）提供标准 ? 按钮，底栏配有【帮助】按钮与【📖 使用帮助】超链接，支持 F1 键一键唤醒本地离线手册；底栏【恢复默认】严格执行恢复系统默认值。

2.4 极速批注与上下双行标注排布 (`CNQ` / `NOTEQUICK`)

在工程实际快速校审时，若每画一个云线都弹窗打断，审图思路极易被中断。本工具提供了高效率的免弹窗快速落图机制：

上下双行规范排布

采用托线（Shelf line）上下双层结构：上方呈现清晰加粗标题（如“【1】 待修改”），下方呈现轻量日期戳。折弯拐角处自动生成等边实心小三角形标记，几何重心严格重合于折点。

免弹窗快速放置

执行 CNQ（或底栏勾选急速批注），框选云线并点选引线后，系统直接以预设短语秒级生成批注，零弹窗打扰，鼠标连贯拖拽落图。

S 键快速切词 (1-8 黄金短语直选)

引线拖拽时按 S 键，命令栏与动态输入直接展开与设置 UI 完全对齐的 8 大黄金精炼短语，按数字键 1~8 秒切；按 T 键 即时输入自定义内容；空格或回车直接确认！

标题与审查意见内容解耦保护

在以往图纸标注中，常见标题被长篇审查正文冲刷覆盖的问题。本工具在底层严格做了字段解耦：无论标题选择默认的“待修改”还是手动输入自定义标题，第一行均完整保留呈现；详细意见内容独立排版在下方或扩展字典中，绝不发生文字冲突或内容丢失。

2.6 生命周期状态机与颜色映射 (`NOTECOLOR`)

遵循工程图纸审查闭环标准，每条批注具备 5 级严格状态机，并与 CAD 视口颜色实时动态联动：

草稿 (Draft) 待办 (Pending) [红色] 已改 (Resolved) [绿色] 已闭环 (Closed) [灰色]

当设计人员完成图纸整改并在面板中回复后，图面上的云线与标注文字颜色会自动由紧迫红（Color 1）转为已改绿（Color 3）；审查人复核无误点击闭环后，自动转为归档灰（Color 8），项目整改进度一目了然。

2.7 批注看板、悬停卡片与底部详情预览 (`CNP` / `NOTEPANEL`)

侧边看板（PaletteSet）是日常集中管理与查看批注的核心入口，具备多项贴合实际绘图的人性化交互：

  • 双击快速居中穿透定位：在列表中双击任意一条批注，AutoCAD 视口自动平滑缩放居中聚焦至对应云线，并自适应保留呼吸安全边距。
  • 多维快速组合过滤：支持按专业（建筑/结构/暖通/给排水/电气）、责任人、严重等级及当前生命周期状态实时筛选。
  • 鼠标悬停卡片 (Tooltip)：鼠标移至某条记录上方时，自动浮动卡片预览完整审查意见与最新整改答复（包含答复人、时间与流转说明）。
  • 底部常驻详情预览面板：单选某条批注，看板底部即时展开完整审查与答复详情，无需频繁点击弹窗。
  • 图面快速状态流转：右键菜单或点击“回复/流转”按钮，即可直接追加整改意见并驱动状态演进（如待办转已改）。
  • 一键直达使用手册：看板顶部工具栏配有【帮助】按钮（或敲命令 CNH / CNHELP），随时随地离线调出本手册查阅。

2.9 图纸跨版本比对与对齐 (`NOTECOMPARE`)

支持设计院新旧两版图纸之间的差异云线自动识别与跨版本流转。在 AutoCAD 2019 及以上版本中，一键联动宿主原生 COMPARE 引擎进行像素级差分；在低版本 CAD 中自动引导通过离线审查包进行比对。

2.10 规范知识库与条文检索 (`NOTEKB` / `NOTEAISEARCH`)

内置主流国家建筑工程审查标准规范（《建筑防火通用规范》、《无障碍设计规范》等典型条款）。输入 NOTEAISEARCH 并输入问题描述，系统基于纯 C# Bigram 模糊算法瞬间匹配最适用的国家标准条款与修改建议，一键回填至批注内容中。

2.11 导出台账清单与图面 7 列闭环汇总表 (`NOTEOUT` / `NOTESUMMARY`)

图面 7 列《图纸审查与整改闭环汇总表》 (`NOTESUMMARY`)

执行 NOTESUMMARY 指定插入点，在图框旁排版绘制原生 CAD 表格。列结构严格包含：序号 | 专业 | 批注标题 | 当前状态 | 批注者 | 审查意见详情 | 整改答复/流转说明。出图晒图即可直接作为正式的工程会审闭环凭证。

零依赖原生 Excel / CSV 台账导出 (`NOTEOUT`)

执行 NOTEOUT 导出无依赖的标准 Excel（.xls）或带 UTF-8 BOM 的 CSV 清单，完整包含审查意见与最新整改答复。无需电脑安装 Office 或任何商业第三方组件，开箱即用，便于汇报与跨单位流转。

2.12 链式 SHA256 防篡改审计 (`NOTEAUDIT`)

每次新建批注、流转状态、修改责任人或追加回复时，系统自动生成包含前序哈希、操作人、时间戳与差异快照的 SHA256 审计块。输入 NOTEAUDIT 可瞬时校验整条批注的历史修改链，确保大型工程审查记录不可抵赖、不可伪造。

3. 五步极速上手指引

从安装到审查闭环的标准工作流
  1. 第一步：启动看板 (CNP) — 在 CAD 命令行输入 CNP，停靠看板将在屏幕侧边展开。
  2. 第二步：新建批注 (CNOTE / CN / CNQ) — 输入 CNOTE 框选生成标准批注；或直接输入 CNQ 启用免弹窗极速批注，拖拽引线时按 S 键秒切 1~8 黄金短语，落图如飞。
  3. 第三步：填写意见 — 弹窗中从审查词典/规范库快速选择条款或手动输入，按回车确定文字放置位置。
  4. 第四步：流转与回复 (CNR) — 施工或设计方修改后，输入 CNR（或在看板选中点击回复），将状态切换为“已改”，云线秒级转绿。
  5. 第五步：输出成果 — 在 CNP 面板直接点击导出，或输入 NOTEOUT 导出全图批注 Excel 台账、输入 NOTESUMMARY 在图框旁生成批注汇总表。

6. 常见问题排查 (FAQ)

Q1: 删除批注时，会不会遗漏残留引线或箭头在图纸上？
A: 不会。系统内置完整的级联删除闭环反应器（Cascade Erase）。无论你在图面删除了文字、云线框还是箭头三角形，关联反应器均会自动将整条批注绑定的全部图元与扩展字典数据同步物理清除，并从看板列表中实时移除。
Q2: 拖拽文字夹点或引线端头时，为什么没有残影而且位置很准？
A: 传统插件依赖 CommandEnded 事件，但夹点拖拽（Grip Edit）不属于普通命令，会导致坐标同步滞后或残留虚影。CAD Auto CloudNote 挂载了 Application.Idle 线程空闲探测，在鼠标松开瞬间立即完成图元坐标校准与对齐。
Q3: 绘制云线时弧线太大或太小，如何快速适配？
A: 输入 CNS 打开设置视窗，调整“弧长比例系数”；或输入 NOTEADAPT 自动检测图纸 DIMSCALE 比例。在 1:100 建筑图纸下，系统会自动换算适宜的可视化弧长。
Q4: 复制带有云线批注的图元，会不会破坏原有批注？
A: 不会相互干扰。CAD Auto CloudNote 内置防克隆冲突引擎：若你成套复制了云线和文字，系统在命令结束时会自动分配新的 NoteId 并生成副本分片；若你仅散件复制了单根云线，系统会自动剥离其关联标记，避免数据交叉污染。
Q5: 图纸长年累月修改，存在无实体关联的死记录怎么清理？
A: 输入 CNS 打开全局设置视窗 -> 在【对象与规则】板块中点击【一键体检】按钮，系统将自动扫描并剔除所有孤儿 XRecord 与失效扩展字典，释放图纸体积。
