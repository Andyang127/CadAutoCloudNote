# 云线批注插件｜7套独立模板可实施建议

>
> 统一底层约定（全部模板共用基础规则，减少重复开发）；业务元数据存放于XRecord，兼容无插件环境（外部打开DWG，云线文字正常可见，仅扩展元数据隐藏）
> 通用逻辑：每套模板独立图层、独立编号前缀、独立元数据字段集、独立预设短句库；切换模板自动加载图层、颜色、编号序列、文字模板；支持单独开关图层打印、按场景筛选、单独导出Excel批注清单。
> 打印字高统一基准：打印高度2.5mm，插件自动根据视口比例换算模型空间字高；文字默认开启白底背景遮罩（透明度0）。
>

## 模板1：施工图审图批注（审图机构）

### 基础图层配置

- 图层名：`AUDIT-NOTE`
- 图层颜色：洋红（红色），线宽0.18mm
- 打印控制：**默认可打印**；可一键关闭图层打印（用于交付干净图纸）

### 编号规则

- 编号前缀：`AUD-001`，序列独立，不和其他模板编号冲突

### 元数据（XRecord挂载字段）


| 字段                   | 说明                                                                                        |
|--------------------------|-----------------------------------------------------------------------------------------------|
| 批注编号             | AUD-001，自动递增                                                                        |
| 涉及专业             | 建筑/结构/给排水/电气/暖通/总图，下拉单选                                   |
| 问题类型             | 图纸表达错误 / 强规范条文不满足 / 图纸矛盾冲突 / 缺图缺大样          |
| 规范条文号          | 填写对应规范条款，例如《建筑设计防火规范》GB50016-2014（2018版）6.4.2 |
| 状态                   | 待设计答复 / 已答复 / 问题关闭                                                    |
| 创建人、创建日期 | 审图人员信息                                                                            |
| 对应图号             | 本批注所在图纸编号                                                                   |


### 预设批注短句库

1. 不满足XX规范第X.X条，请复核修改。
2. 疏散宽度不满足规范限值，请调整。
3. 尺寸标注缺失，请核对完善。
4. 标高存在冲突，请复核。
5. 防火分区面积超限，请重新划分。
6. 此处表达不清，请补充节点详图。
7. 图例与图纸不一致，请统一。
8. 与其他专业图纸冲突，请协调。
9. 图面线型混乱，请调整。
10. 剖面索引缺失，请补画剖切索引。
11. 请核实
12. 请复核


### 业务约束与实施要点

1. 一条批注仅记录**单个问题**，禁止多条问题合并写在同一条云线内，方便逐条销项。
2. 描述严禁模糊，必须写明位置、问题、依据。
3. 导出清单字段：编号、图号、专业、问题类型、规范条文、批注内容、状态、创建人。
4. 适用场景：审图机构正式施工图审查，出具审查意见前的图纸标记。

## 模板2：内部校对 / 自审批注（设计院内部三校两审）

### 基础图层配置

- 图层名：`INTERNAL-CHECK-NOTE`
- 图层颜色：橙色，线宽0.18mm
- 打印控制：**默认关闭打印**，内部校对过程资料，正式出图不打印批注

### 编号规则

- 编号前缀：`CHK-001`，独立序列

### 元数据（XRecord挂载字段）


| 字段                               | 说明                                                       |
|--------------------------------------|--------------------------------------------------------------|
| 批注编号                         | CHK-001，自动递增                                       |
| 校对阶段                         | 初校 / 复校 / 终审，下拉单选                      |
| 涉及专业                         | 建筑/结构/给排水/电气/暖通/总图                 |
| 问题分类                         | 制图错误 / 图纸矛盾 / 缺详图 / 计算书不匹配 |
| 整改状态                         | 待修改 / 已修改 / 复核通过                         |
| 校对人、制图人、创建日期 | 院内校对流程记录                                     |
| 对应图号                         | 图纸编号                                                 |


### 预设批注短句库

1. 本大样与平面尺寸不匹配，请核对统一。
2. 图例缺失，请补充图纸图例表。
3. 轴线编号重复，请修正。
4. 材料说明前后不一致，请统一。
5. 索引指向错误，请调整剖切索引位置。
6. 图面文字重叠，请调整文字位置。
7. 计算书参数与图纸不匹配，请复核。
8. 图名图号与目录不匹配，请修正。
9. 缺少定位轴线，请补充。
10. 引出标注指向不明确，请调整。
11. 请核实
12. 已修改，复核无误


### 业务约束与实施要点

1. 院内内部流转，不对外提交；重点抓制图疏漏、图纸自相矛盾，不局限强规范。
2. 支持校对人复核销项，适合三校两审归档记录。
3. 导出清单字段：编号、图号、专业、校对阶段、问题分类、批注内容、整改状态、校对人。

## 模板3：图纸会审批注（多方会审）

### 基础图层配置

- 图层名：`MEETING-REVIEW-NOTE`
- 图层颜色：黄色，线宽0.18mm
- 打印控制：**默认可打印**，可导出带批注图纸用于会议纪要附件

### 编号规则

- 编号前缀：`MR-001`，独立序列

### 元数据（XRecord挂载字段）


| 字段                   | 说明                                                             |
|--------------------------|--------------------------------------------------------------------|
| 批注编号             | MR-001，自动递增                                              |
| 提出单位             | 建设单位/施工单位/监理单位/设计单位，下拉单选 |
| 问题类型             | 图纸澄清疑问 / 需要设计修改 / 施工可行性问题    |
| 会审纪要编号       | 关联本次图纸会审纪要编号                               |
| 答复状态             | 待设计答复 / 已答复 / 需出具变更洽商                |
| 创建人、创建日期 | 记录提问题人员                                              |
| 对应图号             | 图纸编号                                                       |


### 预设批注短句库

1. 此处构造做法，请设计予以澄清。
2. 本构件现场施工难度大，请设计优化方案。
3. 管线空间不足，请各专业协调调整。
4. 图纸做法与现场地质条件不匹配，请复核。
5. 请设计明确本节点施工工艺要求。
6. 此项纳入图纸会审纪要第X条。
7. 请设计确认材料选型。
8. 预留洞口定位，请进一步明确。
9. 现场实施存在冲突，请各专业协调。
10. 待设计答复。


### 业务约束与实施要点

1. 多方参会，区分【疑问澄清】和【需要修改】两类问题，便于后续生成会审纪要。
2. 批注可作为会审纪要附图，交付建设、监理、施工单位。
3. 导出清单字段：编号、图号、提出单位、问题类型、纪要编号、批注内容、答复状态。

## 模板4：变更洽商过程批注（变更附图标记）

### 基础图层配置

- 图层名：`CHANGE-NOTE`
- 图层颜色：洋红，线宽0.18mm
- 打印控制：**默认可打印**，用于变更单附图打印

### 编号规则

- 编号前缀：`CHG-001`，独立序列

### 元数据（XRecord挂载字段）


| 字段                   | 说明                                                                         |
|--------------------------|--------------------------------------------------------------------------------|
| 批注编号             | CHG-001，自动递增                                                         |
| 变更/洽商编号      | 填写B/C类变更编号，如B2026-03                                         |
| 变更性质             | 新增构件 / 删除构件 / 修改尺寸标高 / 材料替换，下拉单选 |
| 涉及专业             | 建筑/结构/给排水/电气/暖通/总图                                   |
| 状态                   | 草稿 / 正式签发                                                          |
| 创建人、创建日期 | 编制人信息                                                                |
| 对应原图号          | 变更对应的原始施工图编号                                           |


### 预设批注短句库

1. 本范围依据变更【XXX】，取消原有构件。
2. 新增构件，详见变更附图。
3. 构件尺寸调整，原设计此部分作废。
4. 材料规格调整，其余图纸内容不变。
5. 本位置按工程洽商【XXX】调整。
6. 标高调整，详见变更文件。
7. 管道路由修改，按变更实施。
8. 此节点配筋调整，依据变更单。
9. 原设计取消，现场不再施工。
10. 新增预留孔洞，按此实施。


### 业务约束与实施要点

1. 用于**变更单附图标记**，云线框选变更范围，作为变更文件附件。
2. 正式签发后，元数据标记状态为【正式签发】，锁定批注内容，禁止随意修改。
3. 导出清单字段：编号、原图号、专业、变更编号、变更性质、批注内容、状态。

## 模板5：施工交底 / 现场技术批注（施工单位）

### 基础图层配置

- 图层名：`CONSTRUCTION-NOTE`
- 图层颜色：绿色，线宽0.18mm
- 打印控制：**默认可打印**，交底图纸打印携带批注

### 编号规则

- 编号前缀：`CON-001`，独立序列

### 元数据（XRecord挂载字段）


| 字段                   | 说明                                       |
|--------------------------|----------------------------------------------|
| 批注编号             | CON-001，自动递增                       |
| 施工分区             | 一区/二区/地下室等，自定义填写 |
| 工序类型             | 模板/钢筋/混凝土/管线安装等      |
| 风险等级             | 一般提示 / 重大风险，下拉单选   |
| 交底人、创建日期 | 技术交底记录                           |
| 对应图号             | 图纸编号                                 |


### 预设批注短句库

1. 本区域为高支模范围，专项方案已审批。
2. 此处钢筋为重点管控节点，现场需旁站。
3. 该位置预留孔洞，施工时注意保护。
4. 管线交叉位置，按此避让方案施工。
5. 本构件需第三方检测，做好试件留置。
6. 此处为沉降观测点，施工做好保护。
7. 本节点属于关键工序，验收合格方可隐蔽。
8. 构件吊装需编制专项方案。
9. 此区域临边防护必须到位。
10. 重点管控，现场复核尺寸。


### 业务约束与实施要点

1. 用途为**施工提示、风险提醒**，不是纠错批注，措辞不能使用审图类“不满足规范”话术。
2. 用于技术交底、现场管理人员看图，可打印下发班组。
3. 导出清单字段：编号、图号、施工分区、工序类型、风险等级、批注内容、交底人。

3. 导出清单字段：编号、图号、碰撞专业、碰撞类型、批注内容、处理状态。


# 全局插件功能汇总（7套模板共用）

1. 模板切换：下拉菜单一键切换模板，自动切换图层、颜色、编号序列、文字词库。
2. 批量操作：按模板场景，批量显示/隐藏、批量关闭打印。
3. 导出：支持单场景导出或多场景合并导出Excel批注清单。
4. 图元绑定：云线、多行文字、XRecord数据绑定为一组；移动云线文字跟随，删除云线整套批注一并删除。
5. 兼容性：原生CAD图元，无插件打开DWG可正常查看云线文字。
