# 竣工图云线批注模板全套设计要点
> 核心前提：竣工图批注和施工图审图批注目标完全不一样。施工图审图是**找错、提修改意见**；竣工图批注是**记录现场变更、注明和原施工图差异、说明洽商/签证依据**。
> 图层命名建议：`AS-BUILD-NOTE`（AS-BUILD代表竣工图，区分审图`AUDIT_NOTE`图层，不要直接叫“竣工图”，英文图层名在CAD兼容性更好，可设置图层颜色：**洋红/红色**，线宽0.18，打印可关闭）

## 一、元数据（XRecord/XData挂载字段，插件底层存储，导出竣工图差异清单用）
> 这部分是插件的核心能力，区别于普通单纯画云线写字。每条竣工批注必须绑定下面全部属性：
1. **批注编号**：独立编号序列，格式建议 `AS-001、AS-002`，和审图批注`AUD-001`编号隔离，避免序号混淆
2. **变更类型【标签】**（下拉单选，用于筛选导出）
    - 设计变更单（B类）
    - 工程洽商记录（C类）
    - 现场签证（D类）
    - 现场实际调整（无正式洽商，仅小变更）
    - 原图纸勘误（图纸本身错误，现场未改动）
3. **依据文件编号**：文本字段，填写变更单编号/洽商编号，例如：`B2026-03`，导出清单时可关联附件
4. **涉及专业**：建筑/结构/给排水/电气/暖通/总图
5. **状态**：待确认 / 已核对 / 竣工确认
6. **创建人、创建日期**
7. **原施工图图号**：记录变更对应的原始图纸编号
8. **版本号**：竣工图分版时使用

## 二、竣工图专用预设批注短句库（内置下拉模板）
### 🔹 通用变更描述（高频）
1. 本位置按【洽商XXX】现场调整，与原施工图不一致。
2. 此处按设计变更【编号XXX】修改，以现场实际施工为准。
3. 原设计取消，现场未施工。
4. 原设计增加该项内容，详见洽商记录。
5. 构件位置偏移，现场实测定位见本竣工图。
6. 原图纸尺寸有误，现场已按实际调整。
7. 材料型号变更，详见变更文件。
8. 标高调整，以现场竣工实测标高为准。

### 🔹 建筑专业竣工批注
1. 门窗洞口尺寸调整，现场按实际洞口施工。
2. 墙体位置变更，隔墙取消，详见洽商XXX。
3. 屋面做法调整，按变更单【XXX】实施。
4. 地面面层材料更换，现场已施工。
5. 楼梯踏步尺寸现场微调。
6. 外墙洞口位置偏移，以现场竣工为准。

### 🔹 结构专业竣工批注
1. 此构件钢筋调整，依据设计变更【XXX】。
2. 基础埋深现场调整，见勘察补勘资料。
3. 预埋件位置现场偏移，实测定位如图。
4. 次梁取消，按工程洽商XXX执行。
5. 板厚调整，现场已按变更施工。

### 🔹 给排水专业竣工批注
1. 管道路由调整，避开原有管线，详见洽商XXX。
2. 阀门位置、型号变更，现场实际安装如图。
3. 排水立管位置偏移，现场实测定位。
4. 新增雨水口，原图纸未设计。
5. 管道标高调整，以现场竣工标高为准。

### 🔹 电气专业竣工批注
1. 配电箱位置移位，现场实际安装如图。
2. 管线路由变更，避开土建构件。
3. 灯具点位增减，依据洽商XXX。
4. 电缆规格调整，详见变更单【XXX】。

### 🔹 暖通专业竣工批注
1. 风管路由调整，现场避让其他管线。
2. 风口位置增减，按工程洽商XXX施工。
3. 设备基础位置偏移，以现场实测为准。
4. 风机型号变更，详见设计变更文件。

### 🔹 简短备注模板（小变更快速标记）
1. 现场微调，详见洽商XXX
2. 原设计取消
3. 新增构件
4. 材料替换，见变更
5. 实测标高调整

### 🔹 竣工图审核校对类批注（竣工图编制自检用）
1. 与现场竣工资料核对无误。
2. 本变更缺少洽商文件，请补充归档。
3. 多图变更不一致，请统一全图。
4. 变更范围不全，其他图纸同步更新。

## 三、图形样式规范（插件固定参数，竣工图有档案归档要求）
1. **云线**：洋红色（红），云线弧长建议300~800（模型空间可根据比例自动缩放）；**禁止云线遮挡原有竣工图实体线条**，云线尽量框选在空白区域。
2. **文字**
    - 文字图层：`AS-BUILD-NOTE`，独立图层，和图线、审图批注分离
    - 打印字高：固定打印高度2.5mm；插件自动按视口比例换算模型空间字高（关键，竣工图归档对打印字高有硬性要求）
    - 文字背景遮罩：**默认开启**，白底遮罩，透明度0；图纸线条复杂时保证文字可读；导出PDF归档时遮罩有效。
    - 文字内容结构：建议固定模板格式：`AS-001【洽商B2026-03】：此处墙体移位，现场按洽商施工。`
3. **图元组规则**
    - 云线 + 文字 + XRecord数据绑定为一组；移动云线，文字跟随；删除云线，整套批注数据一起删除。
    - 当对方无插件打开图纸：云线、文字正常可见，仅自定义元数据隐藏，满足档案馆接收要求（**非常重要：竣工图交付档案馆，不能依赖插件才能看图**）。

## 四、业务流程与归档规则（插件功能适配）
1. **批注导出模板**：支持一键导出全部竣工批注到Excel，字段包含：编号、图号、变更类型、依据文件、专业、批注内容、创建人。直接作为竣工图差异汇总表，用于归档。
2. **图层打印控制**：`AS-BUILD-NOTE`图层可单独关闭打印。交付档案馆正式竣工蓝图时，**关闭批注图层，不打印云线与批注文字**；带批注版本作为内部对比版本另行保存。
> ✅ 行业惯例：交付档案馆的竣工成品图，图面上不带云线批注；云线差异批注是编制竣工图过程稿的辅助资料。
3. **图纸版本隔离**：插件区分【施工图审图批注】【竣工编制批注】两套独立编号、两套图层，避免同一张图纸混在一起，无法分离。
4. **批量检查功能（可选增强）**
    - 检查：每条竣工批注是否填写了依据文件编号；未填写的标记告警。
    - 检查：同编号变更单在多张图纸中的批注描述是否统一。
